# Matrix Calculator (C++)

A menu-driven console matrix calculator in C++.

## Features

- Add, subtract, multiply or divide a matrix by a scalar
- Add and subtract two matrices
- Multiply two matrices
- Transpose a matrix
- Check whether a matrix is symmetric or an identity matrix, and whether two matrices are equal
- The menu loops until you choose 0 to exit

## Tech stack

C++

## Getting started

```bash
git clone https://github.com/Matiz009/matrix-calculator-cpp.git
cd matrix-calculator-cpp
g++ "matrixAssignment.cpp" -o matrixAssignment && ./matrixAssignment
```

## Project structure

```
matrixAssignment.cpp   Source code

```
